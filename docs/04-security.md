# 安全与治理

## V0 权限等级

- L0：只读公共资料与项目上下文。
- L1：写入草稿、内部文件。
- L2：调用付费模型/产生有限算力成本。
- L3：访问客户数据或外部系统。
- L4：发布、发信、删除、付款、承诺——必须人工审批。

## 强制控制

- Secrets 不进入 Prompt、日志或 Context Store；仅使用环境变量/secret manager。
- 每个 Agent 使用最小权限。
- 成本预算按项目、任务、Agent 三层限制。
- Prompt 注入来源标识；外部网页内容默认不可信。
- 所有工具调用、状态变化、审批保留审计日志。
- 外部 Agent 回传内容必须经过 schema 校验与事实核查。
- 禁止使用未授权 UI 自动化绕过平台限制。
