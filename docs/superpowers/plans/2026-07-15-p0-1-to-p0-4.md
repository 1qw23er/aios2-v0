# AIOS V0 P0-1 to P0-4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a runnable, automatically migrated FastAPI service with the six P0 domain models, core REST endpoints, and a durable SQLite transactional outbox.

**Architecture:** FastAPI lifespan runs Alembic before serving requests. SQLModel entities persist state, DTOs define client contracts, and service functions own transaction boundaries so domain changes and outbox events commit atomically.

**Tech Stack:** Python 3.13+, FastAPI, SQLModel, SQLAlchemy, Alembic, Pydantic 2, SQLite, pytest, HTTPX, Ruff.

```python
class SQLiteEventBus:
    def list_pending(self, limit: int = 100) -> list[Event]:
        statement = (select(Event).where(Event.status == EventStatus.PENDING)
                     .order_by(Event.created_at, Event.id).limit(limit))
        return list(self.session.exec(statement))

    def mark_processed(self, event_id: str) -> Event:
        event = self._get(event_id)
        event.status = EventStatus.PROCESSED
        event.processed_at = now_utc()
        event.last_error = None
        self.session.add(event)
        self.session.commit()
        self.session.refresh(event)
        return event
```

`mark_failed` increments `attempt_count`, records the error, leaves the event pending for later retry, and commits atomically.
