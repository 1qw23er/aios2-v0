# AIOS V0 P0-5 to P0-8 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the AIOS Alpha Foundation with deterministic dependency orchestration, validated external workstation exchange, immutable audit records, and a persistent end-to-end content workflow.

**Architecture:** Domain services commit state, outbox Events, Artifacts, and AuditLog rows atomically. A deterministic Orchestrator consumes `task.completed` Events and activates pre-created downstream tasks only after all dependencies are done; external agents remain file-based and schema validated.

**Tech Stack:** Python 3.12+, FastAPI, SQLModel, SQLAlchemy, Alembic, SQLite, Pydantic 2, jsonschema, pytest, Ruff.
