# 产品简报

## 用户

黎叔：AI 创业公司的唯一人类 CEO。

## 核心问题

Hermes、WorkBuddy、Marvis、扣子、ChatGPT/Codex 分散在不同闭源或开放平台，无法共享实时状态，也无法可靠地相互调用。人类被迫充当消息总线、任务分派员和验收员。

## V0 目标

在一个真实项目中，使至少 3 个 AI 工位连续协作完成：研究 → 策划 → 草稿 → 审核。CEO 每日协调时间目标不超过 15 分钟。

## 成功指标

- 90% 任务有明确输入、输出、负责人、状态和验收标准。
- API Agent 的后续任务可由事件自动触发。
- 闭源 Agent 的人工转交动作少于每任务 2 次。
- 所有结论可追溯到任务、成果物和审批记录。
- 任何外部发布、发信、付款、删除动作必须人工批准。

## 非目标

- 不做通用 Agent 平台。
- 不绕过闭源产品限制。
- 不通过脆弱的 UI 自动化假装“无缝协作”。
- 不让多个模型自由群聊后自行决定高风险操作。
